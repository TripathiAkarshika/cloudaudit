# S3_002: S3 bucket policy allows public access

**Severity:** HIGH · **CIS AWS Foundations Benchmark v1.5.0:** 2.1.5

## Why this matters

An Allow statement with Principal "*" and no Condition makes the bucket contents readable or writable by anyone.

## Verify

```bash
aws s3api get-bucket-policy --bucket BUCKET --query Policy --output text
```

## Remediate

1. Open S3 console > bucket > Permissions > Bucket policy.
2. Delete or scope the statement: replace Principal "*" with specific account ARNs, or add Conditions (aws:SourceVpce, aws:PrincipalOrgID).
3. If the bucket must serve public content, front it with CloudFront and Origin Access Control instead.

```bash
aws s3api delete-bucket-policy --bucket BUCKET   # if the policy is not needed
```

## After fixing

Re-run `cloudaudit scan` and confirm S3_002 no longer appears in the report.
