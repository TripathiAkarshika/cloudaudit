# S3_006: S3 server access logging disabled

**Severity:** LOW · **CIS AWS Foundations Benchmark v1.5.0:** best practice

## Why this matters

Access logs record every request to the bucket, which is the evidence you need when investigating unexpected access.

## Verify

```bash
aws s3api get-bucket-logging --bucket BUCKET
```

## Remediate

1. Create or pick a dedicated log bucket (never the bucket logging itself).
2. Open S3 console > bucket > Properties > Server access logging > Edit > Enable, pointing at the log bucket with a prefix.

```bash
aws s3api put-bucket-logging --bucket BUCKET --bucket-logging-status '{"LoggingEnabled":{"TargetBucket":"LOGBUCKET","TargetPrefix":"BUCKET/"}}'
```

## After fixing

Re-run `cloudaudit scan` and confirm S3_006 no longer appears in the report.
