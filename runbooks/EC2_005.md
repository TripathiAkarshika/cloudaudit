# EC2_005: EBS volume not encrypted

**Severity:** MEDIUM · **CIS AWS Foundations Benchmark v1.5.0:** 2.2.1

## Why this matters

Unencrypted volumes leak through snapshots: a snapshot shared or copied from an unencrypted volume carries the data in the clear.

## Verify

```bash
aws ec2 describe-volumes --volume-ids VOL_ID --query 'Volumes[0].Encrypted'
```

## Remediate

1. Snapshot the volume.
2. Copy the snapshot with encryption enabled.
3. Create an encrypted volume from the copy and swap it onto the instance.

```bash
aws ec2 copy-snapshot --source-snapshot-id SNAP --source-region REGION --encrypted
```

## After fixing

Re-run `cloudaudit scan` and confirm EC2_005 no longer appears in the report.
