# IAM_006: Customer-managed policy allows full admin

**Severity:** HIGH · **CIS AWS Foundations Benchmark v1.5.0:** 1.16

## Why this matters

Action "*" on Resource "*" is the opposite of least privilege: anyone holding this policy is a full administrator, usually by accident.

## Verify

```bash
aws iam get-policy-version --policy-arn ARN --version-id v1
```

## Remediate

1. List who holds the policy: aws iam list-entities-for-policy --policy-arn ARN.
2. Write a scoped replacement from what those principals actually call (check CloudTrail or IAM Access Analyzer policy generation).
3. Create a new policy version with the scoped document and set it as default.

```bash
aws iam create-policy-version --policy-arn ARN --policy-document file://scoped.json --set-as-default
```

## After fixing

Re-run `cloudaudit scan` and confirm IAM_006 no longer appears in the report.
