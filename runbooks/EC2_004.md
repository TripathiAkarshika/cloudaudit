# EC2_004: Default security group allows traffic

**Severity:** MEDIUM · **CIS AWS Foundations Benchmark v1.5.0:** 5.3

## Why this matters

Resources launched without an explicit group land in the default one. If it allows traffic, accidents become exposures.

## Verify

```bash
aws ec2 describe-security-groups --filters Name=group-name,Values=default
```

## Remediate

1. Create purpose-specific security groups for real workloads.
2. Remove every inbound and outbound rule from the default group so it grants nothing.

```bash
aws ec2 revoke-security-group-ingress --group-id SG_ID --ip-permissions "$(aws ec2 describe-security-groups --group-ids SG_ID --query 'SecurityGroups[0].IpPermissions')"
```

## After fixing

Re-run `cloudaudit scan` and confirm EC2_004 no longer appears in the report.
