# IAM_005: Credentials unused for 45+ days

**Severity:** MEDIUM · **CIS AWS Foundations Benchmark v1.5.0:** 1.12

## Why this matters

Dormant credentials belong to people who left or workloads that moved. They provide attack surface with no business value.

## Verify

```bash
aws iam generate-credential-report && aws iam get-credential-report
```

## Remediate

1. Confirm with the owner that the credential is dead.
2. Delete the login profile or deactivate the access key.
3. If the user is gone entirely, remove the user after detaching policies.

```bash
aws iam delete-login-profile --user-name USER
```

## After fixing

Re-run `cloudaudit scan` and confirm IAM_005 no longer appears in the report.
