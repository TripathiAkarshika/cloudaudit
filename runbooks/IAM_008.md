# IAM_008: Weak or missing account password policy

**Severity:** MEDIUM · **CIS AWS Foundations Benchmark v1.5.0:** 1.8

## Why this matters

Without a policy, console users can set short, reused passwords, which is what credential-stuffing attacks count on.

## Verify

```bash
aws iam get-account-password-policy
```

## Remediate

1. IAM console > Account settings > Edit password policy.
2. Require at least 14 characters and prevent reuse of the last 24 passwords.

```bash
aws iam update-account-password-policy --minimum-password-length 14 --password-reuse-prevention 24
```

Re-run `cloudaudit scan` and confirm IAM_008 no longer appears in the report.
