# IAM_003: Console user without MFA

**Severity:** HIGH · **CIS AWS Foundations Benchmark v1.5.0:** 1.10

## Why this matters

A phished or reused password becomes a full console session when MFA is missing.

## Verify

```bash
aws iam list-mfa-devices --user-name USER
```

## Remediate

1. IAM console > Users > USER > Security credentials > Assign MFA device.
2. Enforce it account-wide with an IAM policy that denies all actions except MFA setup when aws:MultiFactorAuthPresent is false.

```bash
aws iam enable-mfa-device --user-name USER --serial-number ARN --authentication-code1 CODE1 --authentication-code2 CODE2
```

## After fixing

Re-run `cloudaudit scan` and confirm IAM_003 no longer appears in the report.
