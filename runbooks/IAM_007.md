# IAM_007: Policy attached directly to user

**Severity:** LOW · **CIS AWS Foundations Benchmark v1.5.0:** 1.15

## Why this matters

Per-user policies drift and become impossible to audit. Groups and roles keep permissions reviewable in one place.

## Verify

```bash
aws iam list-attached-user-policies --user-name USER && aws iam list-user-policies --user-name USER
```

## Remediate

1. Create or pick a group that represents the user's job function.
2. Attach the policy to the group, add the user to the group.
3. Detach the policy from the user and delete inline user policies.

```bash
aws iam detach-user-policy --user-name USER --policy-arn ARN
```

## After fixing

Re-run `cloudaudit scan` and confirm IAM_007 no longer appears in the report.
