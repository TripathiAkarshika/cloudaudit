# IAM_004: Access key not rotated within 90 days

**Severity:** MEDIUM · **CIS AWS Foundations Benchmark v1.5.0:** 1.14

## Why this matters

The longer a key lives, the more places it gets copied to: laptops, CI logs, dotfiles. Rotation caps the blast radius of a quiet leak.

## Verify

```bash
aws iam list-access-keys --user-name USER
```

## Remediate

1. Create a second key for the user, deploy it to the workload, verify traffic on the new key (aws iam get-access-key-last-used).
2. Deactivate the old key, wait a few days, then delete it.

```bash
aws iam create-access-key --user-name USER && aws iam update-access-key --user-name USER --access-key-id OLDKEY --status Inactive
```

## After fixing

Re-run `cloudaudit scan` and confirm IAM_004 no longer appears in the report.
