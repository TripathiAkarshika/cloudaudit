# S3_001: S3 bucket ACL grants public access

**Severity:** HIGH · **CIS AWS Foundations Benchmark v1.5.0:** 2.1.5

## Why this matters

A bucket ACL granting AllUsers or AuthenticatedUsers lets anyone on the internet list or read objects, which is how most public S3 data leaks happen.

## Verify

```bash
aws s3api get-bucket-acl --bucket BUCKET
```

## Remediate

1. Open S3 console > bucket > Permissions > Access control list.
2. Remove every grant for 'Everyone (public access)' and 'Authenticated users group'.
3. Prefer bucket policies plus Block Public Access over ACLs; consider enabling the bucket's ObjectOwnership=BucketOwnerEnforced setting to disable ACLs entirely.

```bash
aws s3api put-bucket-acl --bucket BUCKET --acl private
```

## After fixing

Re-run `cloudaudit scan` and confirm S3_001 no longer appears in the report.
