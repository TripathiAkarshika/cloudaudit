# EC2_003: Security group allows all traffic from anywhere

**Severity:** CRITICAL · **CIS AWS Foundations Benchmark v1.5.0:** best practice

## Why this matters

Protocol -1 from 0.0.0.0/0 exposes every port of every attached resource to the internet: databases, admin panels, everything.

## Verify

```bash
aws ec2 describe-security-groups --group-ids SG_ID
```

## Remediate

1. Identify what the attached instances actually serve.
2. Replace the all-traffic rule with specific protocol/port rules scoped to the narrowest CIDRs that work.

```bash
aws ec2 revoke-security-group-ingress --group-id SG_ID --ip-permissions IpProtocol=-1,IpRanges=[{CidrIp=0.0.0.0/0}]
```

## After fixing

Re-run `cloudaudit scan` and confirm EC2_003 no longer appears in the report.
