# EC2_001: Security group open to the world on SSH (22)

**Severity:** HIGH · **CIS AWS Foundations Benchmark v1.5.0:** 5.2

## Why this matters

SSH open to 0.0.0.0/0 gets brute-forced within minutes of appearing on the internet; it is the most scanned port there is.

## Verify

```bash
aws ec2 describe-security-groups --group-ids SG_ID
```

## Remediate

1. Replace the 0.0.0.0/0 rule with your office/VPN CIDR, or remove it entirely.
2. Prefer AWS Systems Manager Session Manager or EC2 Instance Connect, which need no inbound SSH at all.

```bash
aws ec2 revoke-security-group-ingress --group-id SG_ID --protocol tcp --port 22 --cidr 0.0.0.0/0
```

## After fixing

Re-run `cloudaudit scan` and confirm EC2_001 no longer appears in the report.
