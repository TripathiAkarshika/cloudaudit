# IAM_001: Root account MFA not enabled

**Severity:** CRITICAL · **CIS AWS Foundations Benchmark v1.5.0:** 1.5

## Why this matters

The root user can do anything, including closing the account. A password alone protecting it is the single worst finding an AWS account can have.

## Verify

```bash
aws iam get-account-summary --query 'SummaryMap.AccountMFAEnabled'
```

## Remediate

1. Sign in as root.
2. IAM console > My security credentials > Multi-factor authentication > Assign MFA device.
3. Use a hardware key or authenticator app; store recovery codes offline.

```bash
# MFA for root can only be enabled interactively in the console
```

Re-run `cloudaudit scan` and confirm IAM_001 no longer appears in the report.
