# CT_003: CloudTrail trail is not logging

**Severity:** HIGH · **CIS AWS Foundations Benchmark v1.5.0:** 3.1

## Why this matters

A stopped trail looks configured but records nothing. Attackers call StopLogging for exactly this reason, which is also why the Splunk detections watch for it.

## Verify

```bash
aws cloudtrail get-trail-status --name TRAIL --query IsLogging
```

## Remediate

1. CloudTrail console > Trails > TRAIL > Start logging.
2. Investigate WHY it stopped: search CloudTrail for the StopLogging event and its caller.

```bash
aws cloudtrail start-logging --name TRAIL
```

## After fixing

Re-run `cloudaudit scan` and confirm CT_003 no longer appears in the report.
