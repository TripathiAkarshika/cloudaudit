# S3_005: S3 bucket versioning disabled

**Severity:** LOW · **CIS AWS Foundations Benchmark v1.5.0:** best practice

## Why this matters

Versioning is the undo button for S3: it protects against accidental deletes, overwrites, and some ransomware patterns.

## Verify

```bash
aws s3api get-bucket-versioning --bucket BUCKET
```

## Remediate

1. Open S3 console > bucket > Properties > Bucket Versioning > Edit > Enable.
2. Add a lifecycle rule to expire old noncurrent versions so storage cost stays bounded.

```bash
aws s3api put-bucket-versioning --bucket BUCKET --versioning-configuration Status=Enabled
```

Re-run `cloudaudit scan` and confirm S3_005 no longer appears in the report.
