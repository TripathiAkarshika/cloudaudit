# EC2_006: EBS encryption by default disabled

**Severity:** MEDIUM · **CIS AWS Foundations Benchmark v1.5.0:** 2.2.1

## Why this matters

One region-level toggle makes every future volume encrypted automatically, eliminating this whole class of finding.

## Verify

```bash
aws ec2 get-ebs-encryption-by-default
```

## Remediate

1. EC2 console > Account attributes (right sidebar) > Data protection and security > EBS encryption > Manage > Enable.
2. Repeat per region you operate in.

```bash
aws ec2 enable-ebs-encryption-by-default --region REGION
```

## After fixing

Re-run `cloudaudit scan` and confirm EC2_006 no longer appears in the report.
