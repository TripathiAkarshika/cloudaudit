# CT_002: CloudTrail log file validation disabled

**Severity:** MEDIUM · **CIS AWS Foundations Benchmark v1.5.0:** 3.2

## Why this matters

Validation writes signed digest files so you can prove delivered logs were not modified or deleted, which matters the day the logs matter.

## Verify

```bash
aws cloudtrail describe-trails --query 'trailList[].{Name:Name,Validation:LogFileValidationEnabled}'
```

## Remediate

1. CloudTrail console > Trails > TRAIL > Edit > enable Log file validation.

```bash
aws cloudtrail update-trail --name TRAIL --enable-log-file-validation
```

## After fixing

Re-run `cloudaudit scan` and confirm CT_002 no longer appears in the report.
