# S3_003: S3 Block Public Access not fully enabled

**Severity:** HIGH · **CIS AWS Foundations Benchmark v1.5.0:** 2.1.5

## Why this matters

Block Public Access is the account seatbelt: with all four flags on, a mistaken public ACL or policy is ignored instead of exposing data.

## Verify

```bash
aws s3api get-public-access-block --bucket BUCKET
```

## Remediate

1. Open S3 console > bucket > Permissions > Block public access > Edit.
2. Enable all four settings and save.
3. Also set it account-wide under S3 > Block Public Access settings for this account.

```bash
aws s3api put-public-access-block --bucket BUCKET --public-access-block-configuration BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true
```

## After fixing

Re-run `cloudaudit scan` and confirm S3_003 no longer appears in the report.
