# EC2_007: Instance does not enforce IMDSv2

**Severity:** MEDIUM · **CIS AWS Foundations Benchmark v1.5.0:** 5.6

## Why this matters

IMDSv1 answers unauthenticated metadata requests, so any SSRF bug in an app on the instance can steal the instance role's credentials. IMDSv2 requires a session token and blocks this.

## Verify

```bash
aws ec2 describe-instances --instance-ids I_ID --query 'Reservations[0].Instances[0].MetadataOptions'
```

## Remediate

1. Verify your SDKs are modern enough for IMDSv2 (all current AWS SDKs are).
2. Set HttpTokens=required on the instance; set it in launch templates so new instances comply.

```bash
aws ec2 modify-instance-metadata-options --instance-id I_ID --http-tokens required --http-endpoint enabled
```

## After fixing

Re-run `cloudaudit scan` and confirm EC2_007 no longer appears in the report.
