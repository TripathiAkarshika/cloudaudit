# S3_004: S3 bucket default encryption disabled

**Severity:** MEDIUM · **CIS AWS Foundations Benchmark v1.5.0:** best practice

## Why this matters

Default encryption guarantees every new object is encrypted at rest even when the uploader forgets to ask for it.

## Verify

```bash
aws s3api get-bucket-encryption --bucket BUCKET
```

## Remediate

1. Open S3 console > bucket > Properties > Default encryption > Edit.
2. Choose SSE-S3 (AES-256) or SSE-KMS with a customer managed key for audit trails.

```bash
aws s3api put-bucket-encryption --bucket BUCKET --server-side-encryption-configuration '{"Rules":[{"ApplyServerSideEncryptionByDefault":{"SSEAlgorithm":"AES256"}}]}'
```

## After fixing

Re-run `cloudaudit scan` and confirm S3_004 no longer appears in the report.
