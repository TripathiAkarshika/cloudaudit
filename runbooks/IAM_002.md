# IAM_002: Root account access keys exist

**Severity:** CRITICAL · **CIS AWS Foundations Benchmark v1.5.0:** 1.4

## Why this matters

Root access keys are permanent programmatic superuser credentials. If they leak, the whole account is owned; nothing should ever use them.

## Verify

```bash
aws iam get-account-summary --query 'SummaryMap.AccountAccessKeysPresent'
```

## Remediate

1. Sign in as root > My security credentials > Access keys.
2. Delete every root access key.
3. Create an IAM role or user with only the permissions the workload needs instead.

```bash
# Root keys must be deleted from the root user's security credentials page
```

## After fixing

Re-run `cloudaudit scan` and confirm IAM_002 no longer appears in the report.
