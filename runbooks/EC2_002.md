# EC2_002: Security group open to the world on RDP (3389)

**Severity:** HIGH · **CIS AWS Foundations Benchmark v1.5.0:** 5.2

## Why this matters

Exposed RDP is a top initial-access vector for ransomware operators.

## Verify

```bash
aws ec2 describe-security-groups --group-ids SG_ID
```

## Remediate

1. Remove the 0.0.0.0/0 rule for 3389.
2. Reach Windows hosts through a VPN, a bastion, or Systems Manager Fleet Manager instead.

```bash
aws ec2 revoke-security-group-ingress --group-id SG_ID --protocol tcp --port 3389 --cidr 0.0.0.0/0
```

## After fixing

Re-run `cloudaudit scan` and confirm EC2_002 no longer appears in the report.
